# mesh-mind

**LIVE: https://sjgant80-hub.github.io/mesh-mind/**

against the union — no center, provenance kept, doors held, at κ = 0.618. The verdict is
law; the light is its twin.

## The one new law — gated 34/34, zero baselines

`mesh.mjs` composes the vendored kernels verbatim and adds:

- **NO CENTER** — arrival node, shard listing order, and fold partition never shape the
  verdict; a stranger cannot collapse the shared shadow.
- **PROVENANCE** — the union couples shards, never merges them: every fold keeps its holder.
- **φ-IDENTITY** — nodes take golden-angle phases; no two collide, at any count.
- **DOORS EVERYWHERE** — money/legal/irreversible/external/private hold at the mesh level:
  never auto-collapsed, never even lit as a spectrum.
- **THE TWIN** — `renderEvent` / `dream` / `wake` model the collapse as light (Born rule,
  κ-couplers, live phases): the distribution equals the support shares exactly, power is
  conserved through every held state, and every event is stamped `simulated light`.

The κ boundary is exact to the bit: an intent covered 309/500 reuses (309/500 IS 0.618,
the same double); 308/500 does not.

## Limits, stated plainly

No real photons — the photonic layer is a software twin (exact arithmetic modelling
interference and Born measurement), stamped `simulated light` on every event it renders;
photonic hardware is lab engineering, not this repo. No networked nodes — the four demo
nodes run in one page; shards over a real wire is a next build, not a claim. No learning,
no minds — deterministic arithmetic plus one seeded sampler, nothing else.

## Run the gate

```bash
node --test mesh.test.mjs
node /path/to/witness.mjs mutate mesh.mjs --timeout 20000 --cap 400 --test node --test mesh.test.mjs
```

The page inlines the gated kernels verbatim (`build-page.mjs` is a fixpoint; CI diffs the
rebuild). Demo shards are generated from the estate index by `gen-shards.mjs` — a fold
without a description is refused, never silently dropped.
